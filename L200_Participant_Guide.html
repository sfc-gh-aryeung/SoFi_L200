3Module 1: AI_EXTRACTAI Function

AI_EXTRACT pulls fields out of a document — either as a simple question/answer map, or a full JSON schema with repeating line items.

Question-map form — single invoice

View the source document: invoice_nexgen_office_solutions.pdf

SELECT AI_EXTRACT( file => TO_FILE('@sofi_finance_l200.documents.doc_ai_samples', 'invoice_nexgen_office_solutions.pdf'), responseFormat => { 'vendor_name': 'Who is the vendor on this invoice?', 'invoice_number': 'What is the invoice number?', 'total_amount': 'What is the total amount due?' } ) AS extracted_fields;
Full JSON schema with repeating line items — second invoice

View the source document: invoice_cloudguard_security.pdf

SELECT AI_EXTRACT( file => TO_FILE('@sofi_finance_l200.documents.doc_ai_samples', 'invoice_cloudguard_security.pdf'), responseFormat => { 'schema': { 'type': 'object', 'properties': { 'vendor_name': {'type': 'string'}, 'invoice_number': {'type': 'string'}, 'invoice_date': {'type': 'string'}, 'total_amount': {'type': 'string'}, 'line_items': { 'description': 'Line items table with description, quantity, and amount columns', 'type': 'object', 'column_ordering': ['description', 'quantity', 'amount'], 'properties': { 'description': {'description': 'Item description', 'type': 'array'}, 'quantity': {'description': 'Quantity', 'type': 'array'}, 'amount': {'description': 'Amount', 'type': 'array'} } } } } } ) AS extracted;
Paste both queries above into the Step 3 blanks in L200_01_Follow_Along.sql.

Both invoices — including line items — were already extracted into documents.invoice_extracts when your account was provisioned, using this exact same schema:

SELECT * FROM sofi_finance_l200.documents.invoice_extracts;
Paste this into the last Step 3 blank in L200_01_Follow_Along.sql.

line_items comes back as parallel arrays — description[], quantity[], and amount[], all indexed the same way — rather than a table. Use LATERAL FLATTEN to zip them back into one normal row per line item:

Make it human-readable
SELECT source_file, vendor_name, invoice_number, li.index + 1 AS line_number, line_items:description[li.index]::STRING AS description, line_items:quantity[li.index]::STRING AS quantity, line_items:amount[li.index]::STRING AS amount FROM sofi_finance_l200.documents.invoice_extracts, LATERAL FLATTEN(input => line_items:description) li;
Paste this into the new Step 3 blank in L200_01_Follow_Along.sql.
Use case: This is exactly how Procurement matches PO line items against the 6,162 Coupa/Ironclad approvals over $100K — one AI_EXTRACT call per invoice instead of manual data entry.
4Module 2: AI_CLASSIFYAI Function

AI_CLASSIFY labels a document against categories you define — no training data or model required.

This step loops over all 6 PDFs in the stage — the two you haven't seen linked yet: sofi_q2_2026_earnings_transcript.pdf and robinhood_q2_2026_earnings_call_excerpt.pdf. The other four are linked in their own steps below.

Try it
SELECT relative_path, AI_CLASSIFY( TO_FILE('@sofi_finance_l200.documents.doc_ai_samples', relative_path), ['invoice', 'earnings call transcript', 'legal contract'] ):labels[0]::STRING AS predicted_doc_type FROM DIRECTORY(@sofi_finance_l200.documents.doc_ai_samples) WHERE relative_path ILIKE '%.pdf';
Paste this into the Step 4 blank in L200_01_Follow_Along.sql.

Compare your live results against the pre-built table:

SELECT * FROM sofi_finance_l200.documents.document_classification;
Paste this into the second Step 4 blank in L200_01_Follow_Along.sql.
Use case: An inbound document stage could auto-route every new file to the correct downstream pipeline (AP, Legal, IR) the moment it lands — no manual triage.
5Module 3: AI_PARSE_DOCUMENT, AI_FILTER, AI_REDACTAI Function

AI_PARSE_DOCUMENT converts a PDF into clean text — required before AI_FILTER, AI_REDACT, or AI_SUMMARIZE_AGG, since those only accept text, not files.

Parse the contract

View the source document: sofi_capped_call_contract.pdf

SELECT AI_PARSE_DOCUMENT( TO_FILE('@sofi_finance_l200.documents.doc_ai_samples', 'sofi_capped_call_contract.pdf'), {'mode': 'OCR'} ):content::STRING AS parsed_text;
Paste this into the first Step 5 blank in L200_01_Follow_Along.sql.

This is a real, SEC-filed legal contract — SoFi's Capped Call Early Unwind Agreement, filed as an 8-K exhibit.

The query above is a one-off SELECT — it doesn't save anything. The contract_parsed table used in the next two steps was already built for you when your account was provisioned, using this same AI_PARSE_DOCUMENT call. You're not creating that table yourself.
AI_FILTER — a yes/no question usable in a WHERE clause
SELECT source_file FROM sofi_finance_l200.documents.contract_parsed WHERE AI_FILTER( 'Does this legal contract text contain a specific counterparty name or signatory that should be reviewed for confidentiality before external sharing? ' || SUBSTR(parsed_text, 1, 4000) );
Paste this into the second Step 5 blank in L200_01_Follow_Along.sql.
AI_REDACT — masks sensitive spans using built-in default categories
SELECT AI_REDACT(SUBSTR(parsed_text, 1, 4000)) AS redacted_excerpt FROM sofi_finance_l200.documents.contract_parsed;
Paste this into the third Step 5 blank in L200_01_Follow_Along.sql.
Use case: Internal Audit runs this exact pattern across every SOX-relevant contract for continuous compliance monitoring — flag-first, review-second, instead of manual document review.
6Module 4: AI_TRANSCRIBE, AI_SENTIMENT, AI_SUMMARIZE_AGGAI Function

AI_TRANSCRIBE converts audio directly into text — no separate transcription service.

Try it — a real 6-minute clip from Robinhood's Q2 2026 earnings call

Listen to the source audio: robinhood_q2_2026_earnings_call_clip.mp3

SELECT AI_TRANSCRIBE(TO_FILE('@sofi_finance_l200.documents.doc_ai_samples', 'robinhood_q2_2026_earnings_call_clip.mp3')):text::STRING AS transcript, AI_TRANSCRIBE(TO_FILE('@sofi_finance_l200.documents.doc_ai_samples', 'robinhood_q2_2026_earnings_call_clip.mp3')):audio_duration::FLOAT AS duration_seconds;
Paste this into the first Step 6 blank in L200_01_Follow_Along.sql.
AI_SENTIMENT — scores text for sentiment
SELECT source_file, overall_sentiment FROM sofi_finance_l200.documents.transcript_sentiment;
Paste this into the second Step 6 blank in L200_01_Follow_Along.sql.
AI_SUMMARIZE_AGG — an aggregate function rolling many rows into one narrative
SELECT AI_SUMMARIZE_AGG(SUBSTR(transcript_text, 1, 4000)) AS portfolio_summary FROM sofi_finance_l200.documents.transcript_sentiment;
Paste this into the third Step 6 blank in L200_01_Follow_Along.sql.
Use case: Competitive Strategy tracks sentiment across SoFi's and competitors' earnings calls quarter over quarter, and gets an auto-generated "earnings season" summary for the weekly leadership readout.
7Capstone: AI_COMPLETEAI Function

Here's the reveal: this is the same audio file you just transcribed, sentiment-scored, and summarized in the previous step — but now AI_COMPLETE reasons directly over the raw audio, in one call, with zero transcription step.

Where AI_EXTRACT, AI_CLASSIFY, and AI_TRANSCRIBE are each purpose-built for one task, AI_COMPLETE is the flexible, general-purpose function in the Cortex AI family — it takes a model, a custom prompt, an optional file (audio/image/video), and a structured JSON schema.

Same source audio as the previous step: robinhood_q2_2026_earnings_call_clip.mp3

Try it
SELECT AI_COMPLETE( 'gemini-3.1-pro', 'Analyze this earnings call audio directly. Return overall tone, sentiment, and up to 3 key topics discussed as JSON. Return ONLY raw JSON, no markdown.', TO_FILE('@sofi_finance_l200.documents.doc_ai_samples', 'robinhood_q2_2026_earnings_call_clip.mp3'), {}, { 'type': 'json', 'schema': { 'type': 'object', 'properties': { 'tone': {'type': 'string'}, 'sentiment': {'type': 'string'}, 'key_topics': {'type': 'array', 'items': {'type': 'string'}} }, 'required': ['tone', 'sentiment', 'key_topics'] } } ) AS audio_analysis;
Paste this into the first Step 7 blank in L200_01_Follow_Along.sql.

Compare against the pre-built table:

SELECT * FROM sofi_finance_l200.documents.audio_complete_analysis;
Paste this into the second Step 7 blank in L200_01_Follow_Along.sql.
When to use it: custom or open-ended reasoning a fixed extraction schema can't capture, or direct multimodal analysis of audio/video/images without a separate transcription or OCR step. Use case: Competitive Strategy gets tone and key topics from a competitor earnings call in a single step — no separate transcription pipeline required.
